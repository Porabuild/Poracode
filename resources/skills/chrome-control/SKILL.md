# Chrome Control

Use Poracode's Chrome MCP when a task depends on the user's current Chrome tabs, authenticated sessions, or installed extensions.

## Workflow

1. List tabs and attach to the relevant existing tab instead of opening duplicates.
2. Inspect the page before typing, clicking, or evaluating scripts.
3. Keep actions scoped to the requested site and task.
4. Verify the resulting URL or visible state after each meaningful action.
5. Pause before irreversible submissions, purchases, deletions, or messages unless the user explicitly authorized them.

Treat cookies, page storage, and signed-in content as sensitive user data.
