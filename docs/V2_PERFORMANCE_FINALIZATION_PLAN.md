## Measurement and completion rules

- Investigate repeatable input-queue p95 worsening above `max(2 ms, 10%)` under matched load. This is a working test rule, not a universal product SLO. Hangs, data loss, authorization and ownership failures are material at any latency.
- A failed run stays failed. Source/helper proof, observer integrity, functional checks and performance measurements are separate. Reuse passing evidence only when relevant source/dependency/environment/workload inputs match.
- GPU-process CPU is not hardware GPU utilization or VRAM. RSS/footprint and logical-owner bounds are not private-memory measurements or proof of a leak. Record unavailable counters explicitly.
